# Admin CMS for Categories & Subcategories Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the static `lib/categories.ts` / `lib/subcategories.ts` data with a Postgres-backed database, and give a single admin user a web UI to create/edit/delete categories and subcategories (copy, colors, charms, portfolio videos), with individual categories still able to opt into a hand-built custom React component instead of the generic template.

**Architecture:** Prisma + Postgres for storage, a single env-configured admin login with a signed cookie session, Next.js Route Handlers under `/admin/api/*` for CRUD, a presigned-S3-URL flow for file uploads, and Server Components that read categories/subcategories from Prisma and pass fully-resolved data down to the existing (now prop-only) `CategoryDetail`/`SubcategoryDetail` components. Admin saves call `revalidatePath` so the public pages update immediately.

**Tech Stack:** Next.js 16 (App Router), Prisma + PostgreSQL (Neon/Supabase/Vercel Postgres — any standard `DATABASE_URL`), `bcryptjs` + `jose` for auth, `@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner` for uploads, `zod` for input validation, Tailwind (already configured, unused so far) for admin UI, `vitest` for the pure-logic unit tests.

**Spec:** `docs/superpowers/specs/2026-09-22-admin-cms-design.md`

## Global Constraints

- Single shared admin login only — no user table, no roles, no signup (per spec).
- No server-side image processing — admin uploads pre-cleaned files as-is (per spec).
- `Category`/`Subcategory` are two separate Prisma models, not one self-referencing table (per spec).
- Custom-template categories still get a DB row (`usesCustomTemplate = true`) for nav/ordering; the registry lookup happens in code, not the DB (per spec).
- Existing `/public` asset files are NOT re-uploaded to S3 during migration — their existing paths are stored as-is; only new admin uploads go through S3 (per spec).
- **Assumption (not in spec, flagging here):** `components/Navigation.tsx`'s hardcoded category/subcategory menu arrays (`SERVICE_ITEMS`, `PORTFOLIO_ITEMS`, `VIDEO_EDITING_SUBS`) stay manually maintained in this plan — they are not wired to read from the DB. A developer still adds one line to `Navigation.tsx` when a new category/subcategory should appear in the nav menus. Making the nav dynamic is a reasonable follow-up but is out of scope here to keep this plan shippable.
- No integration test harness (real DB, real HTTP) exists in this repo. Pure logic (validation, auth token sign/verify, the migration mapper, the presigned-URL param builder) gets real Vitest unit tests. Route handlers, pages, and the Prisma-backed CRUD flows are verified manually against a running dev server and a real dev database (curl + Prisma Studio / `psql`) — each task below says exactly what to run and what to expect.

```ts
import type { Category } from '@/lib/categories'
import type { Subcategory } from '@/lib/subcategories'
import type { CategoryInput, SubcategoryInput } from '@/lib/validation'

export function categoryToPrismaInput(c: Category, order: number): CategoryInput {

    slug: c.slug,
    name: c.name,

    accent: c.accent,
    nextSlug: c.nextSlug,
    usesCustomTemplate: false,
    order,

function resolveCharms(s: Subcategory): string[] | null {
  if (!s.charmsDir || !s.charmCount) return null
  return Array.from({ length: s.charmCount }, (_, i) => `${s.charmsDir}/charm-${i + 1}.png`)

    bg: s.bg,
    logo: s.logo ?? null,
    cover: s.cover,
    portfolioVideos: s.portfolioVideos ?? null,
    charms: resolveCharms(s),
```

```ts
// lib/categoryQueries.ts
import { prisma } from '@/lib/prisma'
import type { Category, Subcategory } from '@prisma/client'

export type CategoryWithSubs = Category & { subcategories: Subcategory[] }

export async function getCategoryWithSubcategories(slug: string): Promise<CategoryWithSubs | null> {
  return prisma.category.findUnique({
    where: { slug },
    include: { subcategories: { orderBy: { order: 'asc' } } },
  })
}

export async function getNextCategory(nextSlug: string): Promise<Category | null> {
  return prisma.category.findUnique({ where: { slug: nextSlug } })
}

export async function getSubcategoryDetail(
  categorySlug: string,
  pieceSlug: string
): Promise<{ category: Category; subcategory: Subcategory } | null> {
  const category = await prisma.category.findUnique({ where: { slug: categorySlug } })
  if (!category) return null
  const subcategory = await prisma.subcategory.findFirst({
    where: { categoryId: category.id, slug: pieceSlug },
  })
  if (!subcategory) return null
  return { category, subcategory }
}

export async function listCategoriesForStaticParams(): Promise<{ slug: string }[]> {
  const categories = await prisma.category.findMany({ select: { slug: true } })
  return categories
}

export async function listAllSubcategorySlugs(): Promise<{ slug: string; piece: string }[]> {
  const subs = await prisma.subcategory.findMany({
    select: { slug: true, category: { select: { slug: true } } },
  })
  return subs.map(s => ({ slug: s.category.slug, piece: s.slug }))
}
```

```ts
// lib/auth.ts
import bcrypt from 'bcryptjs'
import { SignJWT, jwtVerify } from 'jose'

export const SESSION_COOKIE_NAME = 'admin_session'

function getSecretKey() {
  const secret = process.env.SESSION_SECRET
  if (!secret) throw new Error('SESSION_SECRET is not set')
  return new TextEncoder().encode(secret)
}

export async function verifyAdminPassword(password: string): Promise<boolean> {
  const hash = process.env.ADMIN_PASSWORD_HASH
  if (!hash) return false
  return bcrypt.compare(password, hash)
}

export async function createSessionToken(): Promise<string> {
  return new SignJWT({ role: 'admin' })
    .setProtectedHeader({ alg: 'HS256' })
    .setIssuedAt()
    .setExpirationTime('30d')
    .sign(getSecretKey())
}

export async function verifySessionToken(token: string): Promise<boolean> {
  try {
    await jwtVerify(token, getSecretKey())
    return true
  } catch {
    return false
  }
}
```

```ts
export async function POST(request: Request) {
```

```ts
// middleware.ts
import { NextRequest, NextResponse } from 'next/server'
import { verifySessionToken, SESSION_COOKIE_NAME } from '@/lib/auth'

export const config = {
  matcher: ['/admin/:path*'],
}

export async function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl
  if (pathname === '/admin/login' || pathname === '/admin/api/login') {
    return NextResponse.next()
  }

  const token = request.cookies.get(SESSION_COOKIE_NAME)?.value
  const valid = token ? await verifySessionToken(token) : false

  if (!valid) {
    if (pathname.startsWith('/admin/api/')) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })
    }
    return NextResponse.redirect(new URL('/admin/login', request.url))
  }

  return NextResponse.next()
}
```

```ts
import { revalidatePath } from 'next/cache'
import { prisma } from '@/lib/prisma'
import { categoryInputSchema } from '@/lib/validation'

export async function GET(_request: Request, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params

  if (!category) return NextResponse.json({ error: 'Not found' }, { status: 404 })

export async function PATCH(request: Request, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params
  const body = await request.json()
  const parsed = categoryInputSchema.partial().safeParse(body)

  }
```

```ts
// lib/s3.ts
import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3'
import { getSignedUrl } from '@aws-sdk/s3-request-presigner'

function getClient() {
  return new S3Client({
    region: process.env.AWS_REGION!,
    credentials: {
      accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
    },
  })
}

export async function buildPresignedUploadUrl(
  key: string,
  contentType: string
): Promise<{ uploadUrl: string; publicUrl: string }> {
  const client = getClient()
  const command = new PutObjectCommand({
    Bucket: process.env.S3_BUCKET_NAME!,
    Key: key,
    ContentType: contentType,
  })
  const uploadUrl = await getSignedUrl(client, command, { expiresIn: 300 })
  const publicUrl = `${process.env.S3_PUBLIC_BASE_URL}/${key}`
  return { uploadUrl, publicUrl }
}
```

```ts
import { NextResponse } from 'next/server'
import { buildPresignedUploadUrl } from '@/lib/s3'

export async function POST(request: Request) {
  const { filename, contentType } = await request.json()
  if (!filename || !contentType) {
    return NextResponse.json({ error: 'filename and contentType are required' }, { status: 400 })
  }
  const key = `uploads/${Date.now()}-${filename.replace(/[^a-zA-Z0-9._-]/g, '_')}`
  const { uploadUrl, publicUrl } = await buildPresignedUploadUrl(key, contentType)
  return NextResponse.json({ uploadUrl, publicUrl })
}
```

- [ ] **Step 1: Write the reusable upload field**

```tsx
// components/admin/FileUploadField.tsx
'use client'

import { useState } from 'react'

async function uploadOne(file: File): Promise<string> {
  const res = await fetch('/admin/api/uploads', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ filename: file.name, contentType: file.type }),
  })
  if (!res.ok) throw new Error('Failed to get upload URL')
  const { uploadUrl, publicUrl } = await res.json()

  const putRes = await fetch(uploadUrl, {
    method: 'PUT',
    headers: { 'Content-Type': file.type },
    body: file,
  })
  if (!putRes.ok) throw new Error('Upload to S3 failed')
  return publicUrl
}

export default function FileUploadField({
  label,
  value,
  onChange,
  multiple = false,
  accept,
}: {
  label: string
  value: string[]
  onChange: (urls: string[]) => void
  multiple?: boolean
  accept?: string
}) {
  const [uploading, setUploading] = useState(false)
  const [error, setError] = useState('')

  async function handleFiles(files: FileList | null) {
    if (!files || files.length === 0) return
    setUploading(true)
    setError('')
    try {
      const urls = await Promise.all(Array.from(files).map(uploadOne))
      onChange(multiple ? [...value, ...urls] : urls)
    } catch {
      setError('Upload failed — try again')
    } finally {
      setUploading(false)
    }
  }

  function removeAt(i: number) {
    onChange(value.filter((_, idx) => idx !== i))
  }

  return (
    <div>
      <span className="text-sm font-medium">{label}</span>
      <input
        type="file"
        multiple={multiple}
        accept={accept}
        onChange={e => handleFiles(e.target.files)}
        className="mt-1 block w-full text-sm"
      />
      {uploading && <p className="text-sm text-gray-500">Uploading…</p>}
      {error && <p className="text-sm text-red-600">{error}</p>}
      <ul className="mt-2 space-y-1">
        {value.map((url, i) => (
          <li key={url} className="flex items-center justify-between text-sm text-gray-600">
            <span className="truncate">{url}</span>
            <button type="button" onClick={() => removeAt(i)} className="ml-2 text-red-600">
              Remove
            </button>
          </li>
        ))}
      </ul>
    </div>
  )
}
```
